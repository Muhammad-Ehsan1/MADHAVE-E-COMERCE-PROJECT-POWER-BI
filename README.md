# MADHAVE-E-COMERCE-PROJECT-POWER-BI
Developed an interactive Power BI dashboard for Madhave E-commerce store, showcasing key metrics like total sales, profit, quantity sold, and average order value. Utilized various visualizations (bar, donut, and horizontal bar charts) and applied filters for quarterly and city-specific analysis. Conducted data cleaning, sorting, filtering, and pivot table creation using Power Query.
